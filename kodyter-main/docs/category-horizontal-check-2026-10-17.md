# Горизонтальный слайдер категорий — 17.10.2026

По уточнению заказчика вертикальный список категорий на главной заменён горизонтальным. Этот отчёт заменяет описание направления прокрутки в `category-slider-check-2026-10-17.md`.

На телефоне карточки высотой 88 px располагаются в один ряд с видимым краем следующей карточки. Стрелки перемещают список влево и вправо. На широком экране текущие пять категорий помещаются в один ряд. Ранее удалённый нижний блок «Собрать заказ» не возвращён.

## Проверка

- Локальная геометрия 360, 390, 768, 1366, 1920 px: ширина документа не превышает ширину окна; все карточки находятся на одной строке. Измерения в `category-horizontal-check-2026-10-17.json`.
- Стрелки перемещают `scrollLeft`, `scrollTop` остаётся 0; начальная/конечная кнопка отключается на соответствующей границе.
- Tab до последней категории: карточка видна полностью; Enter открывает `/catalog?category=5`.
- Исправлен случай частично видимого клавиатурного фокуса: докрутка выполняется только при `:focus-visible`. Клик по видимому краю соседней карточки открывает `/catalog?category=2` с первого нажатия.
- TypeScript и production-сборка Vite успешно выполнены на Vercel для окончательной версии.
- Опубликованная главная проверена при ширине 390 px: карточки 300 × 88 px, горизонтальная прокрутка стрелками работает, ширина документа 375 px, вертикальная прокрутка самого слайдера 0.

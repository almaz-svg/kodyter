# Anasym: рабочий MVP

Подтверждённый стек: React + TypeScript, Django REST Framework, PostgreSQL. Тестовые условия: email/пароль, оплата при получении, KZT, фиксированная доставка 1500. Все коммерческие данные демонстрационные.

## Границы компонентов
- `backend/`: пользователи, сессии, каталог, неизменяемые снимки заказа, переходы статусов, назначения, сообщения о проблемах; миграции и интеграционные тесты API.
- `frontend/src/`: витрина, категории, карточка товара, локальная гостевая корзина, вход и оформление.
- `frontend/src/Portals.tsx`: кабинеты покупателя, администратора, курьера; запрос обновлений каждые 15 секунд.
- `docker-compose.yml`: PostgreSQL, Django и веб-прокси; постоянный том БД.
- `docs/`: установка, резервное копирование, руководство администратора, результаты испытаний.

## Порядок
1. Зафиксировать API, затем параллельно реализовать backend, витрину и кабинеты.
2. Добавить тесты прав доступа, последовательности статусов, идемпотентности, снимков цен и блокировки курьеров.
3. Соединить формы с реальным API, показать ошибки сервера, проверить основной путь в браузере.
4. Проверить ширины 360,390,768,1366,1920, сборку TypeScript и сохранность данных.
5. Подготовить контейнерную тестовую среду, случайные пароли в игнорируемом файле и инструкции.

## Дизайн
Основные источники — два предоставленных заказчиком изображения. Зелёный #07382c для шапки, первого экрана и подвала; кремовый #f6f1e7 для витрины; золото #d4b16b для акцентов и кнопок. Заголовки с засечками, интерфейсные подписи нейтральные. Последовательность: шапка → первый экран → преимущества → категории → о нас → контакты → подвал. На мобильном — удобная нижняя навигация. Изображения устройств не используются. Подписка Refero недоступна; сторонняя стилистика не подменяет референсы.

## Критерии
AT-01…AT-14 из пользовательского ТЗ; проверки в недоступных браузерах и HTTPS на невыбранном хостинге не считать пройденными. Не создавать публичную публикацию до выбора площадки. Полный MVP допускает демонстрационное наполнение, но не фиктивный успех операций или локальную имитацию прав.

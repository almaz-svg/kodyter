# Каталог: покупка и выбранное количество

Проверено 16 октября 2026 в локальной тестовой среде http://127.0.0.1:5174/catalog.

В карточке вместо одиночного «+» появилась кнопка «Купить». Она добавляет одну единицу в корзину. После добавления показаны фактическое количество, кнопки уменьшения/увеличения и ссылка «В корзину». При нуле возвращается «Купить». Каталог показывает общее количество единиц и сумму без доставки; мобильная навигация показывает количество на значке корзины. Используется существующее состояние корзины без отдельного счётчика.

Проверки в браузере:

- Покупка классического круассана → 1 шт., 890 ₸.
- Увеличение до двух и добавление булочки → 3 шт., 2 570 ₸.
- Перезагрузка сохраняет состав и счётчики.
- Удаление булочки из карточки → 2 шт., 1 780 ₸.
- Переход в корзину показывает те же две единицы; с доставкой — 3 280 ₸.
- Уменьшение количества в корзине отражается в каталоге после возврата.
- Уменьшение последнего товара до нуля убирает итоговый блок и восстанавливает кнопку покупки.
- На ширинах 360, 390, 768, 1366 и 1920 px ширина страницы равна ширине области просмотра; элементы управления не выходят за карточку. Измерения: `catalog-cart-responsive-2026-10-16.json`.

Независимая проверка обработчиков компонентов подтвердила ограничение 99 единиц и запрет увеличения недоступного товара с сохранением возможности уменьшить количество.

Финальная сборка TypeScript/Vite успешна. Существующие 22 фронтенд-теста прошли. Серверный код не изменялся. Новые заказы и платежи при этой проверке не создавались; добавленные для проверки позиции удалены из корзины.

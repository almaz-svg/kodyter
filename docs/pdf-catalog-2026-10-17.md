## Повторное наполнение

Данные: `backend/shop/data/pdf_catalog_20261017.json`.

В настроенном окружении приложения доступны команды:

```powershell
./backend/.venv/Scripts/python.exe backend/manage.py import_pdf_catalog --dry-run
./backend/.venv/Scripts/python.exe backend/manage.py import_pdf_catalog
```

Команда работает только при `DEMO_MODE=true`. Сначала проверяет все строки, категории и локальные файлы, затем атомарно добавляет недостающие товары. Существующие товары определяются по уникальным для этого набора URL фотографий и пропускаются без изменений. Перед импортом в опубликованную среду нужно сначала развернуть и проверить статические изображения. Для cloud использовать отдельные настройки `anasym-bakery`, описанные в `vercel-deployment.md`.
